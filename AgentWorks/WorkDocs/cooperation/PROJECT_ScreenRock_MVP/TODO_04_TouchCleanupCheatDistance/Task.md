# Task

## Context
- 드래그 종료 후 마지막 터치 위치에 국소 블러가 남는 현상을 수정한다.
- 좌측 상단 보이지 않는 초기화 치트 버튼을 추가한다.
- 하루 진행 완료에 필요한 문지름 거리를 약 10배 늘린다.

## Current Understanding
- 마지막 터치 위치가 영구 윤기 레이어에도 사용되어 국소 블러가 잔류했다.
- 손끝 반사와 영구 윤기를 별도 레이어로 분리해야 한다.

## Decision Notes
- 손끝 반사는 `IsPetting` 중에만 생성하고 종료 즉시 Widget tree에서 제거한다.
- 영구 윤기는 고정된 상단 좌측의 넓은 반사로 표시한다.
- 치트 버튼은 SafeArea 내부 좌측 상단 48×48 투명 터치 영역으로 둔다.
- 일일 목표와 전체 윤기 목표를 함께 10배 늘려 진행 비율을 유지한다.

## Implementation Notes
- `rock.touch.highlight`로 손끝 반사 생명주기를 Widget 테스트한다.
- `rock.cheat.reset` 입력이 신규·레거시 저장 키와 화면 상태를 함께 초기화한다.
- 일일 목표를 1,000에서 10,000, 전체 윤기 목표를 5,000에서 50,000으로 변경했다.

## Result
- `flutter analyze` 문제 없음
- 테스트 5개 통과
- Android debug APK 빌드 및 에뮬레이터 설치 성공
- 실제 에뮬레이터에서 드래그 종료 후 국소 블러 제거와 좌측 상단 초기화 확인
