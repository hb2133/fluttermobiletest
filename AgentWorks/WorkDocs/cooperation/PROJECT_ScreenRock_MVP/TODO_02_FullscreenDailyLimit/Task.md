# Task

## Context
- UI가 화면 상단에 몰리는 배치를 전체 화면에 자연스럽게 분산한다.
- 하루 한 번만 가능했던 쓰다듬기를 일일 최대 횟수까지 반복 가능하게 한다.

## Current Understanding
- 헤더, 돌멩이, 상태 그룹을 가용 높이 안에서 균등 배치한다.
- 하루 최대 쓰다듬기는 10회이며, 최대 도달 후 다음 로컬 날짜에 0회부터 다시 시작한다.
- 영구 윤기는 누적 쓰다듬기 총합을 기준으로 서서히 증가한다.

## Observed Issues
- 기존 `Column`은 최소 높이를 채웠지만 기본 시작 정렬이라 화면 아래가 크게 비었다.
- 기존 저장 모델은 날짜별 횟수가 없어 일일 반복 입력을 표현할 수 없었다.

## Decision Notes
- 기존 1일 기록은 최초 마이그레이션에서 누적 1회와 당일 1회로 보존한다.
- 일일 진행은 10개의 작은 점으로 조용하게 표시한다.

## Implementation Notes
- `Column`의 세 그룹을 전체 가용 높이에서 `spaceEvenly`로 배치했다.
- 일일 진행을 10개의 점과 `오늘 n / 10번` 문구로 표현했다.
- 누적 횟수, 오늘 횟수, 마지막 날짜를 로컬 저장하고 다음 날짜에는 오늘 횟수를 0으로 해석한다.
- 기존 `shine_days` 저장값을 새 누적 횟수 형식으로 읽는 호환 경로를 추가했다.

## Result
- `flutter analyze` 문제 없음
- Controller, 저장 마이그레이션, 390×844 Widget 테스트 4개 통과
- Android debug APK 빌드와 에뮬레이터 설치 성공
- 실제 에뮬레이터에서 1회부터 10회까지 입력하고 최대치 안내 전환 확인
