# Task

## Context
- 일부 화면 폭에서 UI가 왼쪽으로 치우치는 문제를 바로잡는다.
- 일일 점 표시를 진행 바로 바꾸고 돌을 실사 이미지로 교체한다.
- 쓰다듬을 때 광택 변화가 즉시 느껴지는 피드백을 강화한다.

## Current Understanding
- 스크롤 콘텐츠의 최소 폭을 명시하고 각 그룹을 무한 폭 중앙 정렬해야 한다.
- 실사 돌은 투명 배경 PNG 자산으로 제공하고 Flutter 오버레이로 동적 윤기를 표현한다.
- 진행 피드백은 연속형 진행 바, 돌의 확대, 이동 하이라이트, 반짝임 아이콘을 조합한다.

## Observed Issues
- 기존 세로 스크롤 콘텐츠는 최소 높이만 지정되어 일부 넓은 뷰포트에서 폭 정렬이 불명확했다.
- 10개 점과 숫자 문구는 단계형 인상을 주고 윤기 누적의 즉각적인 시각 변화가 약했다.

## Decision Notes
- 실사 자산은 built-in image generation으로 생성하고 크로마 제거한 PNG를 프로젝트에 포함한다.
- 쓰다듬기 횟수 대신 드래그 이동 거리를 연속 진행도로 환산한다.
- 처음에는 밝기 68%의 무광 상태로 시작하고, 오늘의 진행과 누적 진행을 합쳐 최대 118% 밝기와 강한 표면 반사를 표현한다.

## Implementation Notes
- 스크롤 콘텐츠에 뷰포트 최소 폭을 지정하고 헤더, 돌, 진행 영역을 명시적으로 중앙 정렬했다.
- 10개 점과 숫자 횟수 문구를 제거하고 애니메이션 `LinearProgressIndicator`로 교체했다.
- `assets/images/river_stone.png` 실사 자산과 투명 배경을 적용했다.
- 드래그 이동 거리마다 진행 상태를 즉시 반영하고 손을 떼는 시점에 로컬 저장한다.
- 돌의 무광/유광 밝기 차이, 손끝을 따르는 반사, 확대, 흰색 반짝임을 적용했다.
- 기존 횟수 저장 데이터는 1회당 100 진행도로 변환한다.

## Result
- `flutter analyze` 문제 없음
- 연속 거리 누적, 다음 날 초기화, 저장 마이그레이션, 1200px 중앙 정렬을 포함한 테스트 5개 통과
- Android debug APK 빌드 및 에뮬레이터 설치 성공
- 실제 에뮬레이터에서 한 번의 긴 드래그로 진행 바가 연속 상승하고 돌의 밝기와 반사가 변화하는 것을 확인
