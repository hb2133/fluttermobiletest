# Electronic Tofu MVP

## Summary
- 휴대폰을 흔들면 출렁이고, 강한 충격이 누적되면 금이 가거나 부서지는 전자 두부 MVP를 구현한다.

## Background
- 첫 Flutter 모바일 프로젝트로 센서 입력, 상태 관리, 애니메이션, Widget 테스트를 작은 범위에서 경험한다.

## Scope
- 단일 `TofuHomeBasePanel`과 전용 Controller/Section 구조
- 가속도계 기반 흔들기 감지
- 두부의 안정/흔들림/금감/부서짐 상태 표현
- 새 두부 교체와 테스트 가능한 탭 입력
- 기본 Widget 및 Controller 테스트
